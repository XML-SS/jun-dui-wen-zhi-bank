# 军队文职公共科目刷题宝

基于 2023 版官方考试大纲与 2021–2025 年考生回忆真题 / 机构高频考点整理的离线刷题系统。

## 项目结构

```
jun-dui-wen-zhi-bank/
├── README.md              # 本文件：架构说明
├── docs/
│   └── 做题技巧总结.md     # 大纲对齐的完整做题技巧
├── scripts/
│   └── build_bank.py      # 题库生成器（唯一数据源）
├── web/
│   └── index.html         # 刷题前端（单文件，离线可用）
└── push.ps1               # 一键推送到 GitHub
```

## 架构

```
┌─────────────────────────────────────────────────┐
│  scripts/build_bank.py                          │
│  ┌─────────────┐  ┌──────────────┐  ┌────────┐  │
│  │ 精选真题风格 │  │ 知识点库展开 │  │ 模板生成│  │
│  │ (CURATED)   │+│ (KP)         │+│ 数列/资分│ │
│  └──────┬──────┘  └──────┬───────┘  └───┬────┘  │
│         └────────────────┼──────────────┘       │
│                          ▼                      │
│              BANK = []  (1100+ 题)               │
│                          │                      │
│           json.dumps → 注入 HTML 模板            │
└──────────────────────────┼──────────────────────┘
                           ▼
                web/index.html (单文件)
                ┌──────────────────────┐
                │  Fisher–Yates 洗牌    │
                │  按配额抽卷           │
                │  计时 / 记分 / 分模块  │
                │  重新测试 = 全新组合   │
                └──────────────────────┘
```

### 数据流

1. `build_bank.py` 内三条数据线合并去重：
   - **CURATED**：手写真题风格题（约 70 题，含年份标签）
   - **KP**：知识点正确陈述 + 3 干扰项，模板化展开
   - **生成器**：数列 / 工程 / 行程 / 利润 / 容斥 / 概率 / 方阵 / 资料分析参数化出题
2. 输出 `BANK` JSON，注入 `index.html` 的 `<script>` 中
3. 前端只做抽题、作答、判分、解析展示——**无后端、无网络请求**

### 接口约定（生成器 → 前端）

每道题的 JSON 结构：

```json
{
  "m": "基本知识 | 岗位能力",
  "t": "马克思主义理论 | 人文与社会 | 国防和军队 | 时事政治 | 言语理解 | 数量关系 | 判断推理 | 资料分析",
  "y": "2021-2025",
  "p": 0.5,
  "q": "题干（可含 <span class='hl'> 高亮）",
  "o": ["选项A", "选项B", "选项C", "选项D"],
  "a": 0,
  "e": "解析文本"
}
```

前端接口：

| 函数 | 职责 |
|------|------|
| `build()` | 按「抽题数量 + 模块范围」过滤 → Fisher–Yates 洗牌 → 切片 |
| `start()` | 生成新卷、启动计时 |
| `retest()` | 清空状态，提示用户再次抽卷（组合必与上次不同） |
| `ansQ(i)` | 记录答案、立即判分、展开解析 |
| `submit()` | 停表、总分、分模块得分 |

## 题库规模（每模块 ≥500 题）

| 模块 | 题量 |
|------|------|
| 马克思主义理论 | 500 |
| 人文与社会 | 500 |
| 国防和军队 | 500 |
| 时事政治 | 500 |
| 言语理解 | 500 |
| 数量关系 | 500 |
| 判断推理 | 500 |
| 资料分析 | 500 |
| **合计** | **4000** |

数据源：
- `scripts/data_kp.py` — 基本知识四科知识点库（正确项+干扰项）
- `scripts/data_ability.py` — 岗位能力精选+模板题
- `scripts/build_bank.py` — 合并去重、定向补到500、注入前端

## 使用

### 本地 / 手机

```powershell
# 重新生成题库
$env:MIMO_PYTHON 或 python scripts/build_bank.py
# 输出会覆盖 web/index.html

# 局域网访问（手机同 WiFi）
python -m http.server 8765 --directory web
# 浏览器打开 http://<电脑IP>:8765/
```

或把 `web/index.html` 直接发到手机用浏览器打开（完全离线）。

### 推送到 GitHub

```powershell
./push.ps1
```
