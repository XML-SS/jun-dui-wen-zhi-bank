# 军队文职公共科目做题技巧总结

> 依据：《军队文职人员公开招考笔试公共科目考试大纲》（中央军委政治工作部，2023年8月）  
> 补充：华图教育、红师教育、中国军网等公开备考资料与近年考情分析

---

## 一、考试速览

| 项目 | 内容 |
|------|------|
| 考试方式 | 闭卷笔试 |
| 考试时限 | 120 分钟 |
| 试卷满分 | 100 分 |
| 试题类型 | 全部客观性试题（单选为主） |
| 内容结构 | **第一部分 基本知识**（马原/毛中特/习思想、人文与社会、国防和军队、时事政治）+ **第二部分 岗位能力**（言语、数量、判断、资料） |

**分值参考（近年考情）**：岗位能力约 60 分（提分关键），基本知识约 40 分（记忆为主）。数量关系 10 题 × 1.5 分；判断推理约 10 题；言语约 15–20 题；资料分析分值较高。

**考场总策略**：先易后难；基本知识会的直接选、不会的果断跳过；岗位能力控制每模块用时，资料分析务必留足时间。

---

## 二、第一部分 基本知识——记忆型考点怎么拿分

基本知识以识记、理解为主，考法相对直接，核心是「广覆盖 + 抓高频 + 跟时政」。

### 1. 马克思主义理论

**大纲要点**：马克思主义基本原理（唯物论、辩证法、认识论、唯物史观、剩余价值）、毛泽东思想、中国特色社会主义理论体系、习近平新时代中国特色社会主义思想。

**做题技巧**：

- **哲理题三步走**：先判断考的是唯物论 / 辩证法 / 认识论 / 唯物史观哪一块 → 再对应核心原理关键词 → 选与材料哲理一致的选项。
- **高频对应口诀**（直接秒杀）：
  - 「物质决定意识、意识反作用于物质」→ 一切从实际出发
  - 「矛盾的普遍性与特殊性」→ 共性与个性、具体问题具体分析
  - 「实践是认识的基础」→ 实践决定认识（来源、动力、目的、检验标准）
  - 「人民群众是历史的创造者」→ 群众观点、群众路线
- **毛中特时间线**：把形成时间、代表人物、回答的基本问题做成对照表。
  - 邓小平理论 → 什么是社会主义、怎样建设社会主义
  - 「三个代表」→ 建设什么样的党、怎样建设党
  - 科学发展观 → 实现什么样的发展、怎样发展
  - 习思想 → 新时代坚持和发展什么样的中国特色社会主义、怎样坚持和发展
- **习思想必背框架**：「十个明确」「十四个坚持」「十三个方面成就」；「六个必须坚持」——人民至上、自信自立、守正创新、问题导向、系统观念、胸怀天下。这类题几乎年年考，属于「送分必拿」。
- **选项排除**：说法绝对化（「彻底消灭」「完全取代」「唯一」）、时态错误（把历史事件安到错误时期）、主客颠倒的，一般排除。

### 2. 人文与社会

**大纲要点**：中国历史（古代史、近现代史）、文化常识（中华文化、外域文化）、思想道德（人生观、理想信念、中国精神、核心价值观、道德规范）、法治知识、科学技术。

**做题技巧**：

- **历史题按「时间轴 + 事件链」记忆**：朝代更替顺序、重大改革、近现代史上的关键节点（五四运动、遵义会议、十一届三中全会等）。排序题可用「首尾定位法」——先确定最早/最晚的一项，再排除。
- **文化常识用「人物-作品-主张」三角绑定**：儒家孔孟、道家老庄、法家韩非、释家佛学——问主张选人物，问作品对年代。
- **法律题抓「主体 + 职权 + 程序」**：
  - 宪法是根本法、最高法律效力；
  - 全国人大及其常委会的职权区分（修改宪法 vs 制定基本法律）；
  - 国防相关法规（《国防法》《兵役法》《军队文职人员条例》）是文职考试特色考点，务必单独背。
- **科技题记「第一/首次/最大」**：航天、深海、量子、超级计算机等里程碑事件与时间对应。
- **道德与价值观题**：社会主义核心价值观 24 字（国家层面、社会层面、公民层面各 8 字）必须背到能默写。

### 3. 国防和军队（文职特色，性价比极高）

**大纲要点**：国情国力、中国国防（概述、武装力量、防御性国防政策）、人民军队（性质宗旨、党对军队绝对领导、强军目标、新时代使命任务）。

**做题技巧**：

- **必背核心定义**：
  - 国防的目的：捍卫国家主权、安全和发展利益；
  - 国防的基本类型：自卫型（中国）、扩张型、联盟型、中立型——中国是「自卫型」。
- **武装力量构成**：中国人民解放军 + 中国人民武装警察部队 + 民兵。领导体制：中国共产党对武装力量的绝对领导。
- **人民军队考点**：性质（党的军队、人民的军队、社会主义国家的军队）、宗旨（全心全意为人民服务）、党对军队绝对领导的根本原则和制度（军委主席负责制等）。
- **强军目标**：建设一支听党指挥、能打胜仗、作风优良的人民军队。
- **新时代强军「四梁八柱」**：政治建军、改革强军、科技强军、人才强军、依法治军；「四个现代化」——军事理论、军队组织形态、军事人员、武器装备。
- **记忆方法**：国防与军队部分近 3 年客观题重复率较高（有资料称约 60% 以上），**以近 5 年真题反复刷**，错题直接背结论。

### 4. 时事政治

**大纲要点**：党和国家路线方针政策、重大活动与会议、国家安全形势、国际热点、近一年内国际国内重大事件。

**做题技巧**：

- **时间窗口**：重点覆盖考前 12 个月内的大事（二十大及历次全会、中央经济工作会议、两会、建军节相关讲话、重大军事演习与国防科技成果）。
- **积累方式**：每天 15–20 分钟看「时政早报 / 月度时政汇总」，考前集中刷 100–200 道时政单选即可覆盖大部分。
- **选项技巧**：领导人讲话原文表述一般为正确项；张冠李戴（把 A 会议精神安到 B）、数字夸大/缩小的选项排除。
- **军队文职特色时政**：与国防、军队改革、文职人员制度相关的新闻命中率更高，优先关注。

## 三、第二部分 岗位能力——技巧密集区（约 60 分）

岗位能力对标行测，**重方法、重速度**。以下按四大模块拆解。

### 1. 言语理解与表达（约 15–20 题）

**常见题型**：选词填空、词语辨析、病句辨析、语句顺序、搭配使用、主旨概括、标题填入、标点符号、结语推断、材料鉴赏。

#### （1）选词填空

- **先语境后词义**：不要凭语感硬选。先读上下文找「呼应点」（解释关系、反义关系、并列关系、递进关系），再看选项辨析。
- **高频呼应**：
  - 出现「不是……而是……」「并非」→ 反义呼应；
  - 出现「既……又……」「与……一致」→ 近义/并列呼应；
  - 空后有解释说明 → 选与解释同义的词。
- **实词辨析角度**：含义侧重、语义轻重、感情色彩、搭配对象、语体色彩。
- **成语**：积累高频易错成语（望文生义类：文不加点、差强人意、万人空巷；褒贬误用类：无独有偶、处心积虑）。

#### （2）主旨概括 / 标题填入

- **三步法**：① 通过提问方式确认题型 → ② 阅读文段找主旨句 → ③ 选主旨同义替换项。
- **找主旨的两大抓手**：
  - **关联词**：转折（但是/然而）→ 重点在后；因果（因此/所以）→ 结论是重点；必要条件（只有……才）→ 「才」后是重点；递进（不仅……而且）→ 递进后是重点；并列 → 需全面概括。
  - **行文脉络**：总分、分总、总分总、分总分、分分。总句即主旨；无明显总句时自己概括。
- **干扰项特征**：表述片面（只对应分说部分）、无中生有、偷换概念、过度推断——直接排除。
- **标题填入**：在主旨基础上兼顾「简洁 + 吸引」，一般选主旨同义项，文艺化过度的慎选。

#### （3）语句排序 / 语句填入

- **排序题**：先看选项确定首句（首句一般是背景、定义，不含指代词和关联词后半段）；再找「捆绑集团」（指代词指代对象、关联词配对、时间顺序）。
- **病句题**：六大病因速查——语序不当、搭配不当、成分残缺或赘余、结构混乱、表意不明、不合逻辑。主干划分法（找主谓宾）最快。

#### （4）结语推断

- 话题一致原则：下文要接着文段最后的话题说，不跳跃。选与尾句衔接最紧的选项。

### 2. 数量关系（10 题 × 1.5 分 = 15 分，近年结构：约 2 道数字推理 + 8 道数学运算）

> 文职数量关系难度通常低于国考行测，分值更高，**性价比很高，不建议全部放弃**。

#### （1）数字推理

- **基础数列**：等差、等比、质数、合数、平方/立方数列。
- **组合数列**：交叉数列（奇偶项分开看）、分组数列（两两分组求和/差）。
- **幂数列**：与平方数、立方数靠近的数优先试「修正幂数」。
- **递推数列**：相邻三项之间找「和、差、积、倍」关系，圈三个数先试「前两项运算得到第三项」。
- **操作顺序**：先做差（一次差、二次差）→ 再试比 → 再试和 → 最后试递推。做差是数字推理的第一反应。

#### （2）数学运算高频题型与技巧

| 题型 | 核心方法 |
|------|----------|
| 工程问题 | 赋值法（设总量为完工时间最小公倍数）、效率比例 |
| 行程问题 | 路程=速度×时间；相遇追及公式；画图定位 |
| 排列组合 | 分类用加法、分步用乘法；捆绑法、插空法、隔板法 |
| 概率 | 满足条件的情况数 ÷ 总情况数 |
| 利润问题 | 设成本或销量为特值；列表理清现价、原价、折扣 |
| 容斥原理 | 两集合：A+B-AB；三集合标准公式 |
| 最值问题 | 最不利原则（「至少……才能保证」= 最坏情况 +1） |
| 几何 | 常用面积/体积公式；相似比、勾股定理 |
| 年龄问题 | 年龄差不变，列表倒推 |
| 新定义运算 | 严格按题干给出的运算规则代入，不要用常规运算习惯 |

**通用秒杀技巧**：

1. **代入排除法**：答案数字简单、题干数字复杂时优先用。从「最像正确答案」或居中的选项开始代。
2. **特值法**：题干全是比例/分数，没有具体数值时，设方便计算的特值（100、最小公倍数）。
3. **整除特性**：若题干说「平均分给若干人」「男女比例 3:5」，答案必能被相应数整除，先排除不能整除的选项。
4. **奇偶性 & 尾数法**：加减乘运算的奇偶性可用于排除；四则运算可只算尾数。
5. **选项差距大时大胆估算**：文职选项设置通常差距明显，截位估算完全够用。

**考场建议**：数字推理优先做（题短、分高）；数学运算挑会做的题型先做，行程/排列组合等耗时题可放最后。单题平均不超过 1.5–2 分钟。

### 3. 判断推理（约 10 题，图形推理 + 逻辑判断为大头）

**近年考情**：图形推理 5 道左右、逻辑判断 4 道左右、类比推理 0–1 道、定义判断偶有考查。场景化命题增多（融入军队、国防科技背景）。

#### （1）图形推理

**高频考点（按真题频率）**：

1. **位置规律**：平移、旋转、翻转 → 看「图形完全相同，只是位置变」。
2. **样式规律**：叠加、相减、去同存异、去异存同 → 看「图形相似，部分相同」。
3. **属性规律**：对称性（轴对称/中心对称）、开闭性、曲直性 → 元素凌乱时优先看。
4. **数量规律**：点、线、面、角、素的数量 → 元素凌乱且无明显属性时看。
5. **功能元素**：黑点、白点、箭头标记位置关系。
6. **立体图形**：六面体折纸盒——相对面不相邻、相邻面位置关系；用「相对面排除法」最快。
7. **平面拼合**：把碎片拼成完整图形，注意方向（不能翻转时只旋转）。
8. **黑白块**：部分数、对称性、笔画数、平移规律。

**做题顺序**：先整体看「相同 / 相似 / 相异」三类，再套对应规律表。两段式题（第一段找规律、第二段用规律）——务必把规律验证完再做第二段。

#### （2）逻辑判断

- **翻译推理**：熟记等价命题——
  - 「如果 P 则 Q」→ P⇒Q，逆否命题 ¬Q⇒¬P 等价；
  - 「只有 P 才 Q」→ Q⇒P；
  - 「A 或 B」的否定是「¬A 且 ¬B」。
  - **技巧**：先翻译，再用逆否推理，不要凭日常语感。
- **真假推理**：找矛盾（矛盾必一真一假）→ 确定其余话的真假 → 推出结论。
  - 常见矛盾：「所有是」与「有的不是」；「A→B」与「A 且非 B」。
- **分析推理（文职近年难点）**：
  - 列表法 / 排除法：题干条件多时画表；
  - 最大信息优先：从被提及次数最多的对象入手；
  - 肯定信息优先。
- **削弱与加强**：
  - 先找论点和论据；
  - 削弱力度：否定论点 > 切断联系（拆桥）> 否定论据；
  - 加强力度：肯定论点 > 建立联系（搭桥）> 补充论据；
  - 无关项（话题不一致、诉诸权威/人身）直接排除。
- **日常推理**：选「可能正确」优先选「弱表述」（可能、有些）；选「一定正确」必须从题干直接推出，过度推断的不要。

#### （3）定义判断

- **三步**：① 提取定义主体、客体、原因、目的、方式、条件等关键信息 → ② 逐一对比选项 → ③ 选「符合所有关键信息」的选项。
- **技巧**：不符合主体、不符合目的、方式错误的选项优先排；多定义题先看提问问的是哪个定义。

#### （4）类比推理

- **先横后纵**：先看题干词之间的关系（并列、包含、因果、功能、材料、象征、语法关系），再对比选项。
- **造句法**：用题干两个词造句，套到选项上通顺且关系一致的优先。
- **注意**：关系不止一层时，比较「哪组关系与题干完全一致」，而非只看是否相关。

### 4. 资料分析（分值高、提分快，务必拿高分）

**常见材料类型**：孤立语段、多段语段、统计图、流程图、综合图、混合图文。

#### （1）核心公式（必背）

| 概念 | 公式 |
|------|------|
| 基期量 | 现期量 ÷ (1 + 增长率) |
| 现期量 | 基期量 × (1 + 增长率) |
| 增长量 | 现期量 − 基期量；或 现期量 × 增长率 ÷ (1 + 增长率) |
| 增长率 | (现期量 − 基期量) ÷ 基期量；或 增长量 ÷ 基期量 |
| 年均增长量 | (末期 − 初期) ÷ 年份差 |
| 现期平均数 | 总量 ÷ 个数 |
| 平均数增长率 | (总量增速 − 个数增速) ÷ (1 + 个数增速) |
| 现期倍数 | A ÷ B |
| 翻 n 番 | × 2ⁿ |
| 比重 | 部分 ÷ 整体 |
| 间隔增长率 | r₁ + r₂ + r₁ × r₂ |

#### （2）速算技巧（按优先级练习）

1. **截位直除**（最常用）：选项差距大截两位，差距小截三位。分母截位后直接除。
2. **特殊分数法（百化分）**：把百分数化成分数——
   - 1/2=50%，1/3≈33.3%，1/4=25%，1/5=20%，1/6≈16.7%，1/8=12.5%，1/10=10%，1/20=5%……
   - 增长量计算「n+1 原则」：增长率 ≈ 1/n 时，增长量 ≈ 现期量 ÷ (n+1)；减少量用 n−1。
3. **尾数法**：选项精确到个位且尾数不同时，只算尾数。
4. **首数法 / 首位法**：选项首位不同，只算首位。
5. **差分法**：比较两个分数大小时用（大分数 vs 小分数，差分数）。
6. **放缩估算**：上下限夹逼，锁定唯一选项。

#### （3）高频考点与秒杀口诀

- **增长率比较**：材料给现期量和基期量时，直接比「现期量 ÷ 基期量」即可（不需求出具体增长率）。
- **增长量比较口诀**：**「大大则大」**——现期量大且增长率大，则增长量一定大；「一大一小」时看乘积（现期量 × 增长率）。
- **混合增长率口诀**：**「大小居中，偏向基期量大的一方」**——整体增速一定介于各部分增速之间，且靠近基期量更大的部分。
- **百分点 vs 百分比**：
  - 「增速比上年同期加快 2 个百分点」→ 原增速 = 现增速 − 2%；
  - 「放缓 2 个百分点」→ 原增速 = 现增速 + 2%。
  - **易错点**：百分点用于增长率之差，不能写成「提高了 2%」。
- **隔年增长率**：r₁ + r₂ + r₁×r₂（今年增速 r₁、去年增速 r₂）。
- **基期量比较**：分数性质——分子大分母小的分数值大。

#### （4）做题流程

1. **先看问题**（再看材料）：确认问的是「现期/基期/增长量/增长率/比重/平均数」。
2. **定位数据**：圈出材料中时间、单位、主体名称，防止「时间陷阱」「单位陷阱」（亿 vs 万、% vs ‰）。
3. **列式后先估算再精算**：多数题用截位直除 30 秒内可出答案。
4. **综合分析题**（「能够从资料中推出 / 推出错误的是」）：先看 C、D 选项（命题人常把答案放在后面），从易到难验证；找到正确项直接选，不必全验证。
5. **每天保持 20 题左右训练量**，单篇材料（5 题）控制在 8–10 分钟。

## 四、考场时间分配与蒙题策略（120 分钟）

### 建议时间分配

| 模块 | 建议用时 | 说明 |
|------|----------|------|
| 基本知识 | 15–20 分钟 | 会的直接选，不会的凭第一印象选，不要纠结 |
| 言语理解 | 20–25 分钟 | 选词填空不宜反复改；主旨题找到关联词就走 |
| 数量关系 | 15–20 分钟 | 数字推理优先；数学运算挑 6–8 道会的做，难题战略放弃 |
| 判断推理 | 20–25 分钟 | 图推 40–60 秒/题，没思路就跳过下一张 |
| 资料分析 | 25–30 分钟 | 必须留足，这是最容易提分的模块 |

### 通用蒙题与应试技巧

1. **绝对化表述一般错**：「一定」「所有」「完全」「唯一」——除非教材原文如此。
2. **选「与军队/国防/人民立场一致」的选项**：基本知识涉及价值观、政策表述时，立场正确的选项更可能是答案。
3. **主旨题选「全面概括」项**，不选「片面细节」项。
4. **常识题「符合生活常识 + 无明显错误」优先**。
5. **数量蒙题**：选项差距大时选居中偏大的；几何题带特殊角（30°/45°/60°）计算；选项中有整数优先验证整数。
6. **不要在一道题上超过 2 分钟**——标记后跳过，有时间再回。
7. **答题卡**：做完一个模块就涂一次，防止最后没时间涂卡。

## 六、一页纸速记清单（考前最后看）

**资料分析公式**：基期=现期÷(1+r)；增长量=现期×r/(1+r)，n+1 原则；混合增长居中偏向基期大；百分点是增速之差；比较增长率直接比现期÷基期。

**言语**：转折后是重点；因果找结论；并列需全面；选词先语境呼应后辨析。

**数量**：先做差再试比；代入排除 + 特值 + 整除；「至少保证」用最不利原则。

**判断**：图推先判相同/相似/相异；翻译推理背逆否；削弱看「否定论点」最强；真假题先找矛盾。

**基本知识**：习思想「六个必须坚持」；强军目标「听党指挥、能打胜仗、作风优良」；中国国防类型「自卫型」；核心价值观 24 字；党对军队绝对领导。
